# Raccourcis clavier — Live

Actifs lorsque l’onglet **Live** est affiché (sauf focus dans un champ texte).

| Touche | Action |
|--------|--------|
| **B** | Blackout (invoke univers à zéro + master à 0) |
| **T** | Tap tempo (BPM) |
| **Entrée** | GO — lance la prochaine cue de la liste |
| **Ctrl+Z** | Annule le dernier preset ambiance appliqué (historique court) |

Les cues se gèrent dans la section **Cue list** en haut du Live.
